轻印

Map + Memory = 记录每一段旅程

内测 2.0 Build 2026.06

轻印源于一次简单的想法：旅行本该是轻松愉快的，不该被繁琐的 App 困扰。

我们曾无数次在旅途中打开各种旅游日记、打卡工具，却总被复杂的功能劝退——明明只是想记下"今天去了哪里、看到了什么"，为什么需要填这么多表单？选分类、打标签、写攻略……这些真的有必要吗？

所以轻印决定做减法：在地图上留下脚印，用照片和文字珍藏记忆。没有花哨的功能堆砌，只有你最需要的：打开地图就能看到走过的路，点一下就能记录此刻的心情。简洁、直观、懂你。

愿每一次出发，都能被温柔记录。🌍
