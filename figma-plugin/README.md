# 轻印 - 旅行记忆 Figma 插件

## 功能说明

此 Figma Plugin 可自动生成 **轻印（旅行记忆）** 小程序的完整交互原型图，共 **11 个页面**。

## 生成的页面

| # | 页面名 | 内容 |
|---|--------|------|
| 1 | 日志_旅程列表 | 旅程卡片 + FAB按钮 + 空状态 |
| 2 | 日志_旅程详情 | 图片轮播 + 日记列表 + 返回导航 |
| 3 | 打卡_全屏地图 | 天地图 + 标记点 + 工具栏 |
| 4 | 分享_日志导出 | Tab切换 + 导出卡片 + 操作按钮 |
| 5 | 我的_个人中心 | 头像卡片 + 勋章 + 统计 + 菜单 |
| 6 | Modal_新建旅程 | 表单弹窗 |
| 7 | Modal_小票预览 | 小票风格分享预览 |
| 8 | SubPage_勋章 | 34省勋章网格 + 筛选 + 统计 |
| 9 | Modal_设置 | 设置项列表 |
| 10 | Modal_关于 | 品牌信息 |
| 11 | SubPage_数据洞察 | 月度活跃柱状图 |

## 使用方法

### 前提条件
- **Figma 桌面端**（必须使用桌面版，不支持浏览器版本）
- 一个已打开的 Figma 文件

### 步骤

1. **打开 Figma 桌面端**，创建或打开任意一个文件
2. 在菜单栏点击 **Plugins → Development → Import plugin from manifest...**
3. 选择本项目中的 `figma-plugin/manifest.json` 文件
4. 在 Plugins 菜单中找到 **轻印 Prototype v2**，点击运行
5. 等待约 5-10 秒，所有 11 个页面将自动生成在当前画布上

### 如果遇到问题

- **空白/无内容**：请确保使用的是 **Figma 桌面端最新版**
- **字体加载错误**：插件会自动加载 Inter 字体，首次可能需要等待更长时间
- **重新运行**：先删除画布上的旧内容，再运行插件

## 技术说明

本插件使用了以下关键技术：
- **异步字体加载**: `figma.loadFontAsync()` 确保 Inter 字体可用后才创建文本节点
- **RGB 颜色转换**: 将十六进制颜色转换为 Figma 所需的 0-1 RGB 格式
- **渐变填充**: 使用 `GRADIENT_LINEAR` 类型实现主题色渐变效果
- **Frame 嵌套**: 通过 Frame 容器实现组件化布局
