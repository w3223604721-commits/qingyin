## 关键交互路径

### 路径 1: 创建旅程流程
```
日志首页 → FAB(+) → 新建旅程 Modal → 保存 → 回到旅程列表
```

### 路径 2: 查看旅程详情
```
日志首页 → 点击旅程卡片 → 旅程详情（轮播+日记列表）
  → 点击日记 → 日记详情 Modal（编辑/删除）
  → 添加新日记 → 日记编辑 Modal
```

### 路径 3: 地图打卡流程
```
打卡页 → 点击(+) → 添加打卡 Modal（地点/城市/照片/备注）→ 保存 → 地图标记点更新
打卡页 → 开始记录 → 足迹追踪 → 停止记录 → 足迹回放
```

### 路径 4: 分享流程
```
分享页 → 选择旅程 → 导出图片 / 生成小票
  → 小票预览 → 微信/QQ分享 / 保存相册
  → 自定义模板 → 选图片 → 编辑文字 → 生成预览
```

### 路径 5: 个人中心
```
我的 → 勋章入口 → 勋章页面（筛选/统计）
我的 → 数据洞察 → 洞察详情（4个维度图表）
我的 → 设置 → 账号/回收站/权限/反馈/关于/清除
```

## 页面内状态变化

| 页面 | 状态 | 触发条件 |
|------|------|---------|
| 日志列表 | 空状态 | 无旅程时 |
| 日志列表 | 列表态 | 有旅程时 |
| 日志详情 | 有照片轮播 | 日记中有照片 |
| 日志详情 | 无照片提示 | 日记中无照片 |
| 打卡地图 | 普通态 | 未记录足迹 |
| 打卡地图 | 记录态 | 正在记录足迹（红点闪烁） |
| 打卡地图 | 回放态 | 回放已记录的足迹 |
| 分享 | 日志导出 | 选择"日志导出" tab |
| 分享 | 自定义模板 | 选择"自定义模板" tab |
| 勋章 | 全部 | 展示所有34省 |
| 勋章 | 已点亮 | 仅展示已到达省份 |
| 勋章 | 未点亮 | 仅展示未到达省份 |
